# 个人微信前台模式实施计划

目标：由 AutoReply 自己连接已登录的个人微信，定位明确指定的测试联系人 Q，使用已有本地模型、回复规则和知识库处理启动后的新消息。

依据：用户已授权切换聊天窗口，指定联系人 Q，并明确要求功能在当前项目内实现。前台模式单独显示，不声称满足企业后台不干扰办公的验收；企业运行时保持原能力门禁。

执行采用内联开发和测试驱动。沿用 Electron、RobotJS、已有模型配置及知识库，不安装新的依赖。

- [x] 定义前台会话合同和独立运行时；测试旧消息基线、新消息、重复轮询、生成途中新消息、人工输入、切换客户、暂停、未知发送和重启阻断。
- [x] 实现项目自己的窗口截图、视觉读取、唯一联系人搜索、单次发送和回显确认；发送前重新读取并核对上下文、窗口实例、输入框和像素状态。最后一次异步窗口检查后，同步比对物理屏幕、取消信号和配置版本，再执行单次发送。
- [x] 接入主进程私有 IPC、受限 preload 和首页前台控制；显示真实阶段、错误和持久化回复记录。启动失败返回项目界面。
