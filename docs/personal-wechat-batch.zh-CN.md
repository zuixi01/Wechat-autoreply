# 个人微信批量回复

主页默认使用单联系人自动回复。先完成单联系人验证，再展开“多联系人批量自动回复”，每行填写一个允许回复的完整联系人备注名，最多 500 个；名单保存在当前项目用户配置中。选择支持截图的视觉模型、回复模型并保存规则后，点击“启动批量自动回复”。

程序绑定唯一完整微信主窗口，小型登录辅助窗口不参与聊天窗口选择；两个完整主窗口仍停止接入。授权目标都在顶部时，优先逐个核对本地联系人搜索的唯一匹配，排除网络搜索建议；搜索结果不完整时退回完整列表扫描。完整扫描会确认顶部、滚动并保留重叠行、确认底部，再筛选名单中的未读会话。跨页同名目标会被隔离；列表重排或摘要变化会重新核验。单轮上限 200 次列表截图、10,000 行，达到上限明确停止，不显示已覆盖全部。遍历的是当前客户端聊天列表，不包括已删除、被隐藏或尚未出现在列表中的联系人。

初次处理未读会话时，核对完整聊天标题、单聊、空草稿、未读数量和末条消息摘要，仅将对应的完整入站文字作为待处理消息。仅有小红点时，先定位头像右上角标记并用当前像素确认实心红点，不能把读不清的数字、红色头像或导航栏通知当成未读数量。打开后核对摘要与连续入站消息，将本轮未回复的连续文字一起处理；可见历史达到上限且无法确认这一轮的起点时交给人工核对。无法对应的数量、超过 80 条或截断/非文字消息需要人工核对。启动会处理授权名单中的现有未读消息，页面明确说明这一行为。后续处理保留各会话的独立基线，生成期间的新消息使旧草稿失效并保留任务。

当前打开的授权聊天即使没有未读数字也持续检查：先建立历史基线，再通过完整消息序列判断新增文字。同文字连续来信按序列分别处理，不以摘要或红点作为消息去重依据。

一个桌面只运行一个物理工作循环，依次切换会话、生成、复读及发送。联系人默认使用主页通用回复规则，配置了对象规则时使用该对象策略、模型与知识库。批量模式与单联系人模式互斥，启动一个会先停止另一个。人工暂停、锁屏、休眠和退出会取消在途操作；切换到其他应用只进入等待，不抢回前台，返回微信后再验证。姓名、截图和坐标没有被伪装成原生客户/消息 ID。

SQLite 在打开聊天前保存未读提示，在读取通过后保存会话基线与回复状态，完成的基线也保留并在重启后恢复。单联系人与批量模式共享进度；启动时将每个已保存的联系人核对一次，即使其红点已被人工打开聊天消除。微信重新登录后，用户重新启动服务时须核对新窗口的联系人、空草稿、配置及旧消息连续性，才能继续原进度；运行中突然换窗仍停止，不能确认历史时保留进度交给人工。重启不会自动启用服务。发送后的延迟回显会保持在当前会话，只读复核，不再次生成、输入或发送；确认成功后继续其他联系人。已持久化的未知发送阻止整个个人微信服务重启，不重试 Enter。状态查询优先展示未核对记录及近期记录，未知状态检查覆盖全部历史。

启动会自动关闭图片预览并返回普通聊天导航，不要求用户预先选定某个客户。截断的无关备注不会停止所有目标，可能与授权联系人同名的截断备注仍隔离该目标；只读取可见摘要，不补全隐藏文字。对已验证、窗口实例和配置相同且列表/输入像素完全未变的页面缓存视觉结果，减少重复模型调用；每次导航前仍重新核对当前像素、前台和取消信号。

这是一条个人微信前台截图适配路径，需要专用电脑或接受自动切换聊天。无法证明无干扰后台运行、稳定原生身份或消息完整覆盖，也不解除企业后台运行的能力门禁。企业微信的真实批量适配仍未验证。本功能不等于大规模全天候生产验收完成。

列表扫描、首次连接和模型读取的暂时故障会保留队列并等待恢复，不因连续几次失败清空任务；重试间隔最多 30 秒。通知遮挡时等待移开。浅色主题的真实滚动条用于核对列表是否到顶或到底，无法检测时保留视觉验证。每次成功切换后更新当前会话线索，并由消息驱动再次核对标题后处理。

截图读取请求优先关闭额外模型推理，避免推理消耗整个超时时间而没有返回 JSON。接口明确不支持该参数时，仅协商回退一次，并按接口、模型和凭据分别记住兼容结果；其他请求错误不会被当成兼容问题吞掉。识别结果仍经过完整字段、像素、联系人和草稿核验。仅在实际进入搜索后清理搜索，搜索前的接口超时不会向主窗口按 Esc，也不会覆盖原始错误。联系人搜索结束后只按一次 Esc；仍有经过确认的微信自有搜索浮层时，重新识别并点击聊天导航，避免第二次 Esc 隐藏微信主窗口。

回复不强制一句话或固定结尾标点，可按语义分成 1–3 条气泡；每条确认后保存游标，新来信或本人接话会取消旧计划剩余部分。可选择已导入并启用的 PNG/JPEG 静态表情图片，最多一张，受发送核验和冷却限制。保留有语义的标点，默认去掉末尾中文句号；无效 Unicode 字符会被拦截。本人用词通过现有 LearningStore 保存证据和版本，仅学习核验后的手动外发及明确保存的样本，排除程序生成记录，支持纠正、回滚与删除。
