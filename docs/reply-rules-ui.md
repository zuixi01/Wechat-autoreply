# 回复规则界面简化

2026-10-03，按用户认可的方案完成现有配置流程优化。

- 移除侧栏及独立设置窗口的「模式管理」、顶栏「添加模式」、主页的当前/默认模式选择。
- 主页直接编辑通用回复规则、统一开头和情感分析；规则面板位于常用配置之前。窄窗口可通过「编辑回复规则」直接定位并聚焦输入框。
- 对象用户直接填写专属回复要求，留空沿用通用规则；列表显示通用规则/专属要求，并可按规则类型筛选。
- 知识试答自动使用通用规则，选中对象后使用其实际所属配置和专属要求；规则改变后隐藏过期试答。

## 兼容与使用范围

已有模式及对象数据保留。没有编辑过的旧对象继续沿用原先的规则、开头和自动回复设置；保存专属要求后，使用通用规则与专属要求的组合。专属要求不能放宽通用的事实与业务限制。明确关闭自动回复的对象不会因规则编辑而被开启。

已有暂停的通用规则不会被自动启用，也不会被另一套规则替换；主页可明确选择保存并启用。原配置已暂停的对象，在用户明确选择开启自动回复并保存时，可转到通用配置并保留填写的专属要求。

知识试答及已有本地回复路径已接入专属要求。企业自动回复继续使用后台发布并同步的规则与知识，本次没有改变企业发送授权、发布或核验流程，界面保留了这一提示。浏览器设计页是离线演示，不调用真实模型或微信。
